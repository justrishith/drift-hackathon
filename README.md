# Drift v1 — Hand-Gesture Window Controller

**AI-powered window control via hand gestures on Windows.**

## What it does

Drift translates real-time hand gestures into control commands for Windows windows:
- **Open-palm** → grab/move window (idle_ready state)
- **Pinch spread** → zoom out (`Ctrl+-`)
- **Pinch close** → zoom in
- **Fist held 0.5s** → freeze/kill-switch (`frozen` state)
- **Fast swipe** → throw window to other monitor

The AI runs entirely offline: MediaPipe Tasks `hand_landmarker` (21 landmarks) classifies gestures in real-time on CPU (25-30 FPS).

## AI & Tech Stack

- **Model**: MediaPipe Tasks `hand_landmarker` (`.task` file, ~9MB) — 21 hand landmarks, running on CPU only
- **Language**: Python 3.11
- **Libraries**: `opencv-python`, `mediapipe`, `numpy`, `pywin32` (OS calls behind `dry_run` flag)
- **Architecture**: `camera → tracker → gestures → actuator` — pure-function state machine, no training data, zero cloud

## Hackathon Product Loop (this repo)

The `demo.py` script runs the actual Drift product loop in safe dry-run mode:

1. **Webcam** → MediaPipe hand landmarker → 21 landmarks
2. **Gesture classification**: open palm, push/hold, pinch, swipe, fist kill-switch
3. **Animated OpenCV HUD**: Dynamic-Island-style status pill, neon hand trail, FPS, action feed
4. **Actuator path**: dry-run logs by default; `--live` enables real Windows cursor/window/zoom actions

Run the demo:

```bash
py -3.11 demo.py
```

For real Windows actions after you trust the demo:

```bash
py -3.11 demo.py --live
```

**Controls** (in the demo window):
- Open-palm → see state change to `idle_ready`
- Pinch (thumb-index spread) → `pinch` (zoom out)
- Release pinch → back to `idle`
- Fist held → `frozen` (kill-switch)
- Press **Q** or **ESC** or **Space** to quit

## How AI Is Used

MediaPipe's `hand_landmarker` model processes each webcam frame, producing 21 (x,y,z) hand landmarks. Drift's pure-python gesture module then:

- Computes inter-landmark distances (`thumb_tip` vs `index_tip` for pinch)
- Checks finger extension state via `dist(wrist, tip) > dist(wrist, pip) * 1.12`
- Classifies palm open, pinch, fist, and estimates swipe velocity
- Feeds these into a rule-based state machine (`idle → grab → frozen`, etc.)

All inference is offline — no camera frames leave the laptop, no model downloads at runtime, no cloud API calls.
